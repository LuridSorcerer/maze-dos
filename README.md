# MAZE

A basic DOS-based ASCII maze game, written in C++. 

## Build

This project should be compiled with Borland Turbo C++ 3.0 running in
DOS. Later compilers may work, but have not been tested. Turbo C++ will
be looking for files located in C:\REPOS\MAZE, so the source files will
need to be present there.

1. Place source files in C:\REPOS\MAZE

1. Open MAZE.PRJ in Turbo C++

	> tc maze.prj

1. Compile the project (F9), or Compile and Run (Ctrl+F9)

## Usage

To play the game, compile it (see above), and start it from DOS.

	> maze.exe
	
The player controls the ASCII smiley face and attempts to nagivate it
through the maze. Use the arrow keys to move, and reach the goal.
